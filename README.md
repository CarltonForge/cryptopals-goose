# Cryptopals – Goose

Working through the [Cryptopals Crypto Challenges](https://cryptopals.com/) using [Goose](https://github.com/goose-lang/goose).

This is a learning project focused on developing my understanding of programming, cryptography, data representation and low-level operations using Goose.

I'm implementing the challenges myself, taking the time to understand the concepts behind each solution rather than simply aiming to get something working.
